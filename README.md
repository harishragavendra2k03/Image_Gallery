# 🖼️ Image Gallery

A simple and responsive **Image Gallery Web Application** built using **HTML, CSS, and JavaScript**.

The project allows users to view a collection of images and filter them based on different categories.

## 🚀 Features

- 🖼️ Display images in a gallery layout
- 🔍 Filter images by category
- ⬅️ Previous image navigation
- ➡️ Next image navigation
- 🔀 Image shuffle functionality
- 📱 Responsive design
- ✨ Simple and user-friendly interface

## 🛠️ Technologies Used

- **HTML5** – Creates the structure of the image gallery
- **CSS3** – Provides styling and responsive layout
- **JavaScript** – Handles filtering, navigation, and image interactions

## ▶️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/harishragavendra2k03/Image_Gallery.git
```

2. Open the project folder.

3. Open `Image.html` in your browser.

4. Start exploring the image gallery. 🎉

## 💡 How It Works

The gallery uses JavaScript to manage the images and their categories.

Users can:

- Select a category to filter images.
- Use the **Previous** and **Next** buttons to navigate.
- Shuffle the images to change their order.
- View the images in a responsive gallery layout.
